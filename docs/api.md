## `<scene>`

A scene graph and its renderer over `<gpu>`.

A Scene holds nodes in a tree (each with a position, a rotation and a scale,
and optionally a mesh with a material, or a camera), lights, textures and
the settings of the final image. Scene_render draws it: shadow maps, the
opaque surfaces front to back, the sky, the transparent surfaces back to
front, all in linear HDR, then bloom, tone mapping and gamma into the
target (a window frame or a texture).

```eskiu
Scene scene = gpu.scene()?;
defer scene.release();
SceneGeometry ball = scene_sphere(1.0, 48, 24);
int mesh = scene.add_geometry(&ball)?;
ball.free();
SceneMaterial m = scene_material(SCENE_PBR);
m.diffuse = Vec4{0.9, 0.2, 0.1, 1.0};
int node = scene.add_object(0, mesh, scene.add_material(m));
scene.add_light(scene_directional(Vec3{-0.5, -1.0, -0.3}, Vec3{1.0, 1.0, 1.0}, 2.0));
int cam = scene.add_camera(0, scene_perspective(0.9, 0.1, 100.0));
scene.node(cam).position = Vec3{0.0, 1.0, 4.0};
scene.look_at(cam, Vec3{0.0, 0.0, 0.0}, Vec3{0.0, 1.0, 0.0});
scene.set_camera(cam);
...each frame:
scene.render(frame.view, surface.width, surface.height, surface.format)?;
```

Ids: node 0 is the root, and every node descends from it. Meshes, materials
and textures are numbered from 1; 0 in a node's mesh is no mesh, in its
material the scene's default material (white Blinn), and in a material's
texture field no texture. Lights are numbered from 0. Pointers from node(),
material() and light() are good until the next node, material or light is
added.

### SceneCamera

```eskiu

```

A camera, attached to a node: it sits at the node's origin and looks down the node's -Z
axis with +Y up. fov is the vertical field of view in radians (perspective), height the
visible height in world units (orthographic), near and far the clipping distances, and
aspect the width over height (0 takes the target's).

### SceneNode

```eskiu
struct SceneNode {
    String name;
    int parent;
    List<int> children;
    Vec3 position;
    Quat rotation;
    Vec3 scale;
    bool visible;
    bool alive;
    int mesh;
    int material;
    int camera;
    bool casts_shadows;
    bool receives_shadows;
    uint32 light_mask;
    float opacity;
    int rendering_order;
    int billboard;
    bool ignore_events;
    Mat4 world;
    List<Mat4> joints;
    List<float> weights;
}
```

A node. position, rotation and scale place it in its parent's space (the local matrix is
translation * rotation * scale); world is its world matrix after the last
Scene_update or render. A node that is not visible hides its whole subtree. mesh,
material and camera are ids (0, 0 and -1 when it has none); casts_shadows and
receives_shadows choose its part in shadows, and light_mask the lights that reach it
(SceneLight.influence). opacity (1) fades the node and its subtree: it multiplies down
the tree, a node below 1 is drawn blended (after the opaque surfaces, sorted back to
front, casting no shadow), and one at 0 is not drawn. rendering_order (0) draws the node
before (lower) or after (higher) others whatever its distance, ahead of every other
ordering; with a material that skips the depth test it puts a panel on top. billboard
(SCENE_BILLBOARD_*) turns the node to face the camera. ignore_events keeps the node's mesh out of hit tests
(`<scene/input>`): rays pass through it. alive is false once the node is removed. Change
parent and children through Scene_set_parent and Scene_remove, not by hand.

### Scene

```eskiu
struct Scene {
    Gpu gpu;
    List<SceneNode> nodes;
    List<SceneCamera> cameras;
    List<SceneMesh> meshes;
    List<SceneMaterial> materials;
    List<GpuTexture> textures;
    List<SceneLight> lights;
    int camera;
    Vec4 background;
    *GpuTexture skybox;
    float sky_intensity;
    bool sky_flip;
    GpuTexture sky_faces;
    *GpuIbl ibl;
    ScenePost post;
    uint32 shadow_size;
}
```

A scene and its renderer. background is the linear color behind everything when there
is no skybox; skybox (with sky_intensity, and sky_flip for a cube of six images) is
set by Scene_set_skybox or Scene_set_skybox_faces; ibl by Scene_set_ibl; post holds
the tone mapping, gamma and bloom settings; shadow_size is the width and height of each
shadow map (2048). camera is the node of the camera that renders (-1 is a default camera
at the origin looking down -Z). The lists are the scene's objects by id.

## `<scene/animation>`

Property animations of nodes (`<scene/animation>`).

The model of ViroReact's ViroAnimations. A group animates some of a node's properties
(position, scale, rotation in Euler angles, opacity, the color of its material) to new
values over a duration, after a delay, along an easing curve. A chain runs groups and
other chains one after another (serial) or all at once (parallel). Each group reads the
node's values when it starts, so a relative value (SCENE_ANIM_ADD: "+=90" in
ViroReact) builds on where the earlier groups left the node, and again on each loop.

```eskiu
SceneAnimations anims = scene_animations();
defer anims.free();
int up = anims.group(0.5, SCENE_EASE_IN_OUT);
anims.set(up, SCENE_ANIM_POSITION_Y, SCENE_ANIM_ADD, 1.0);
int spin = anims.group(1.0, SCENE_EASE_LINEAR);
anims.set(spin, SCENE_ANIM_ROTATE_Y, SCENE_ANIM_ADD, 3.14159265);
int[2] both = {up, spin};
int hop = anims.chain(&both[0], 2, false);
anims.play(&scene, node, hop, true, now);
...each frame, before rendering:
anims.update(&scene, now);
```

Times are seconds on any clock that only goes forward (the frame time).

### SCENE_EASE_LINEAR, SCENE_EASE_IN, SCENE_EASE_OUT, SCENE_EASE_IN_OUT, SCENE_EASE_BOUNCE, SCENE_EASE_POWER_DECEL, SCENE_EASE_STEP

```eskiu
const int SCENE_EASE_LINEAR = 0;
const int SCENE_EASE_IN = 1;
const int SCENE_EASE_OUT = 2;
const int SCENE_EASE_IN_OUT = 3;
const int SCENE_EASE_BOUNCE = 4;
const int SCENE_EASE_POWER_DECEL = 5;
const int SCENE_EASE_STEP = 6;
```

Easing curves, ViroReact's timing functions: LINEAR; EASE_IN accelerates through the
first half (2t^2) and is linear after; EASE_OUT is linear through the first half and
slows to a stop; EASE_IN_OUT does both; BOUNCE overshoots to 1.11 at half time and
settles back to 1; POWER_DECEL is 1 - (1 - t)^2; STEP holds the start until the end.

### SCENE_ANIM_POSITION_X, SCENE_ANIM_POSITION_Y, SCENE_ANIM_POSITION_Z, SCENE_ANIM_SCALE_X, SCENE_ANIM_SCALE_Y, SCENE_ANIM_SCALE_Z, SCENE_ANIM_ROTATE_X, SCENE_ANIM_ROTATE_Y, SCENE_ANIM_ROTATE_Z, SCENE_ANIM_OPACITY

## `<scene/geometry>`

Meshes on the CPU, before they go to the GPU (`<scene/geometry>`).

A SceneGeometry is an interleaved vertex array and a uint32 index list. The
procedural shapes (box, sphere, plane, quad) and glTF primitives come in
this form, and Scene_add_geometry uploads one as a mesh:

```eskiu
SceneGeometry g = scene_sphere(1.0, 48, 24);
```

## `<scene/input>`

Hit testing and node events (`<scene/input>`).

A ray from the camera through a point of the image (Scene_screen_ray), or from any
controller, finds the node it hits: Scene_hit_test tests each visible node's mesh
bounds, the box carried through the node's world matrix, so a rotated or scaled
node is tested exactly. A SceneInput turns presses, moves and two-finger gestures into
events on nodes, the way ViroReact's onClick, onDrag, onPinch, onRotate, onHover and
onFuse behave:

```eskiu
SceneInput input = scene_input();
defer input.free();
input.on(cube, SCENE_ON_CLICK | SCENE_ON_DRAG, void(*SceneEvent e) {
    if (e.kind == SCENE_EVENT_CLICK && e.state == SCENE_CLICKED) printf("clicked %d\n", e.node);
});
...for each GpuTouch from <gpu/ui>'s use_gpu_touch:
input.touch(&scene, t, width, height);
```

An event goes to the node hit or, when that node has no handler for it, to its nearest
ancestor that has one (a glTF model's handler on its root node takes the hits on all
of its meshes). The node in the event is that handler's node; target is the node the
ray hit.

### Scene_hit_test


The node ray hits that is drawn on top, into hit: as in ViroReact, hits are taken in

## `<scene/light>`

Lights (`<scene/light>`).

A light is ambient, directional, point or spot. Directional, point and spot
lights may hang from a node: position and direction are then in the node's
space and move with it. Each drawn node takes up to 8 of them (the
directional ones first, then the nearest point and spot lights whose range
reaches it); ambient lights are summed and light everything.

```eskiu
int sun = scene.add_light(scene_directional(Vec3{-0.3, -1.0, -0.4}, Vec3{1.0, 0.95, 0.9}, 2.0));
scene.light(sun).casts_shadows = true;
int lamp = scene.add_light(scene_point(Vec3{0.0, 2.0, 0.0}, Vec3{1.0, 0.6, 0.3}, 3.0, 0.5, 6.0));
```

Intensity multiplies the color: a white light of intensity 1 straight onto
a white Lambert surface lights it to 1. (ViroReact's lights in lumens are
1000 times larger.)

### SCENE_LIGHT_AMBIENT, SCENE_LIGHT_DIRECTIONAL, SCENE_LIGHT_POINT, SCENE_LIGHT_SPOT


The most lights a scene sends to the GPU at once (beyond them, lights are skipped in
the order they were added), and the most a single draw is lit by.

### SCENE_MAX_SHADOWS

```eskiu

```

### SceneLight

```eskiu
struct SceneLight {
    int type;
    bool enabled;
    Vec3 color;
    float intensity;
    int node;
    Vec3 position;
    Vec3 direction;
    float attenuation_start;
    float attenuation_end;
    float falloff;
    float inner_angle;
    float outer_angle;
    uint32 influence;
    bool casts_shadows;
    float shadow_bias;
    float shadow_normal_bias;
    float shadow_opacity;
    float shadow_radius;
    Vec3 shadow_center;
}
```

A light:
- type: one of SCENE_LIGHT_*; enabled turns it on.
- color (linear RGB) times intensity is the light's strength.
- position (point, spot) and direction (directional, spot; it points from the light
  toward what it lights) are in node's space, or the world's when node is -1.
- attenuation_start, attenuation_end, falloff (point, spot): full strength up to start,
  none from end, and 1 - t^(1/falloff) in between, with t going from 0 at start to 1 at
  end (falloff 1 is linear, 2 the default).
- inner_angle and outer_angle (spot): angles from the axis in radians; full strength
  inside the inner one, fading to none at the outer one.
- influence: a bit mask; the light reaches nodes whose light_mask shares a bit.
- casts_shadows (directional): the light gets a layer of the scene's shadow map array
  (Scene.shadow_size texels square), compared with shadow_bias (in the light box's
  depth units) after moving the point shadow_normal_bias texels along its normal; shadow_opacity 1 is a black
  shadow, 0 none. shadow_radius > 0 sets the cube the light sees (half-size, around
  shadow_center, in world space); 0 fits the visible nodes.

## `<scene/material>`

Materials and the shaders made for them (`<scene/material>`).

A SceneMaterial picks a lighting model, its colors and textures, how alpha
is used and how a transparent surface blends with what is behind it.
Start from scene_material, which fills in the defaults:

```eskiu
SceneMaterial m = scene_material(SCENE_PBR);
m.diffuse = Vec4{0.8, 0.1, 0.1, 1.0};
m.roughness = 0.4;
int red = scene.add_material(m);
```

Colors are linear RGB (not sRGB) and may go above 1 for HDR. Texture fields
hold ids from Scene_add_texture and friends; 0 is no texture.

The renderer makes one WGSL shader and pipeline per variant (lighting
model, alpha mode, blend mode, sidedness) and keeps it for every material
that shares the variant; scene_material_key and scene_material_shader are the
pieces it uses.

### SCENE_CONSTANT, SCENE_LAMBERT, SCENE_PHONG, SCENE_BLINN, SCENE_PBR

```eskiu
const int SCENE_CONSTANT = 0;
const int SCENE_LAMBERT = 1;
const int SCENE_PHONG = 2;
const int SCENE_BLINN = 3;
const int SCENE_PBR = 4;
```

Lighting models (SceneMaterial.lighting). CONSTANT shows the diffuse color unlit;
LAMBERT is diffuse light only; PHONG and BLINN add a specular highlight (around the
reflection of the light, or around the half vector); PBR is the metallic-roughness
model (GGX, Smith visibility, Fresnel-Schlick) with image-based ambient light when the
scene has an environment.

### SCENE_ALPHA_OPAQUE, SCENE_ALPHA_MASK, SCENE_ALPHA_BLEND

```eskiu
const int SCENE_ALPHA_OPAQUE = 0;
const int SCENE_ALPHA_MASK = 1;
const int SCENE_ALPHA_BLEND = 2;
```

Alpha modes (SceneMaterial.alpha_mode): the surface is opaque (alpha ignored), cut out
where alpha is below alpha_cutoff, or blended with what is behind it (drawn after the
opaque surfaces, back to front).

### SCENE_BLEND_ALPHA, SCENE_BLEND_ADD, SCENE_BLEND_MULTIPLY, SCENE_BLEND_SUBTRACT, SCENE_BLEND_SCREEN, SCENE_BLEND_PREMULTIPLIED

```eskiu
const int SCENE_BLEND_ALPHA = 0;
const int SCENE_BLEND_ADD = 1;
const int SCENE_BLEND_MULTIPLY = 2;
const int SCENE_BLEND_SUBTRACT = 3;
const int SCENE_BLEND_SCREEN = 4;
const int SCENE_BLEND_PREMULTIPLIED = 5;
```

Blend modes of a SCENE_ALPHA_BLEND material (SceneMaterial.blend_mode), with s the
surface color, a its alpha and d the color behind it: ALPHA is s * a + d * (1 - a);
ADD is d + s * a; MULTIPLY is d * mix(1, s, a); SUBTRACT is d - s * a; SCREEN is
d + s * a * (1 - d); PREMULTIPLIED is s + d * (1 - a), for colors already multiplied
by their alpha.

### SceneUv

```eskiu

    Vec2 scale;
```

How a texture of a material reads its coordinates: set picks the vertex's first (0) or
second (1) texture coordinate; with transform (glTF's KHR_texture_transform) they are

### SceneMaterial

```eskiu
struct SceneMaterial {
    int lighting;
    Vec4 diffuse;
    int diffuse_texture;
    float diffuse_intensity;
    Vec3 specular;
    float shininess;
    int specular_texture;
    int normal_texture;
    float normal_scale;
    Vec3 emissive;
    int emissive_texture;
    float metalness;
    float roughness;
    int metal_rough_texture;
    int occlusion_texture;

    int alpha_mode;

    int blend_mode;
    bool double_sided;

    bool skip_depth_write;
```

A material. Fields by lighting model:
- every model: diffuse (linear RGBA, multiplied by diffuse_texture and the vertex
  color), emissive (added after lighting, times emissive_texture), alpha_mode,

  strength normal_scale; not used by CONSTANT).
- LAMBERT, PHONG, BLINN: diffuse_intensity scales the lit diffuse term; PHONG and BLINN

- PBR: metalness and roughness (times the blue and green channels of
  metal_rough_texture, as glTF stores them) and occlusion_texture (red channel,
  strength occlusion_strength) on the ambient term.
Texture ids come from the Scene that draws the material (0 is none). uv holds how each
texture reads its coordinates, in the order diffuse, specular, normal, emissive,
metal-roughness, occlusion (SCENE_TEX_DIFFUSE and the others).

## `<scene/post>`

Tone mapping, gamma and bloom (`<scene/post>`).

A scene is drawn into an RGBA16Float image in linear light, where values
may go past 1. The last pass maps it to the output: bloom first (the parts
brighter than bloom_threshold, blurred at half size and added back), then
the tone mapping operator, then sRGB encoding when the output format does
not do it.

```eskiu
scene.post.tone_mapping = SCENE_TONE_HABLE;
scene.post.exposure = 0.5;        // stops: the image is scaled by 2^exposure
scene.post.bloom = true;
```

scene_tone_map and scene_srgb compute the same curves on the CPU.

### SCENE_TONE_NONE, SCENE_TONE_REINHARD, SCENE_TONE_EXPOSURE, SCENE_TONE_HABLE

```eskiu
const int SCENE_TONE_NONE = 0;
const int SCENE_TONE_REINHARD = 1;
const int SCENE_TONE_EXPOSURE = 2;
const int SCENE_TONE_HABLE = 3;
```

Tone mapping operators (ScenePost.tone_mapping), on c = color * 2^exposure:
NONE keeps c; REINHARD is c / (1 + c); EXPOSURE is 1 - exp(-c); HABLE is the filmic
curve of Uncharted 2 (A 0.15, B 0.50, C 0.10, D 0.20, E 0.02, F 0.30) divided by its
value at white_point. Each works on the red, green and blue channels separately.

### ScenePost

```eskiu
struct ScenePost {
    int tone_mapping;
    float exposure;
    float white_point;
    bool gamma;
    bool bloom;
    float bloom_threshold;
    float bloom_strength;
    int bloom_passes;
}
```

The final pass's settings; the zero value is no tone mapping, no bloom and sRGB
encoding off (Gpu_scene turns gamma on):
- tone_mapping: a SCENE_TONE_* operator; exposure in stops (0 keeps the brightness);
  white_point for HABLE (0 is 11.2).
- gamma: encode the result to sRGB when the output format is not an sRGB one (an sRGB
  format encodes it itself). Off, a float output gets linear values.
- bloom: add a blur of the bright parts; bloom_threshold is the luminance where it
  starts (0 is 1.0), bloom_strength scales it (0 is 1.0), bloom_passes is the number of
  horizontal and vertical blur pairs at half size (0 is 4; more spreads wider).

### scene_tone_map

```eskiu
Vec3 scene_tone_map(Vec3 c, *ScenePost p)
```

A linear color through p's tone mapping operator and exposure (no bloom, no gamma), as
the final pass computes it.

### scene_srgb

```eskiu
float scene_srgb(float c)
```

A linear value (0 to 1) encoded with the sRGB curve.

### scene_linear

```eskiu
float scene_linear(float c)
```

An sRGB-encoded value (0 to 1) back to linear light.


## `<scene/sky>`

The background of a scene (`<scene/sky>`).

Behind everything a scene shows a solid color (Scene.background) or a cube
map: an environment from `<gpu/ibl>` (GpuIbl.environment, radiance by
direction) with Scene_set_skybox, or six images with Scene_set_skybox_faces.

```eskiu
GpuIbl ibl = gpu.ibl(&sky_hdr, null)?;
scene.set_skybox(&ibl.environment);
scene.set_ibl(&ibl);               // PBR materials take their ambient light from it
```

scene_cube_faces makes the cube of six images on its own.

### scene_cube_faces

```eskiu
Result<GpuTexture, string> scene_cube_faces(*Gpu gpu, *Bitmap faces)
```

A cube texture from six square images of the same size, in the order +X (right), -X
(left), +Y (top), -Y (bottom), +Z (front), -Z (back), stored as sRGB with mipmaps made on
the GPU. These are the usual skybox image sets (OpenGL's cube map convention): drawn
with Scene_set_skybox_faces, the +Z image is what a camera looking down -Z sees.
